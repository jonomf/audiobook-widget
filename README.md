# Media widgets (Audiobooks + Music)

One app, two home-screen widgets that look and behave the same at every size:
- **Audiobooks**: whatever **Libby** or **Audible** is playing. It switches to whichever app starts
  playing; tap the app icon to switch by hand.
- **Music**: whatever **YouTube Music** is playing (merged in from jonomf/ytmusic-widget).

They differ in content and in the controls of the bigger sizes / full panel:

| | Audiobooks | Music |
|---|---|---|
| Lines | title · chapter · time left · author | song · artist · time left · album |
| 3×1 grid / 4×1 covers | other recent books | recent albums and mixes |
| Recent list | books, with chapter and app | songs |
| Controls | chapter back/next, skip back/forward, speed, bookmark | previous/next, YouTube Music's own buttons (like, dislike…) |
| Extra in full panel | bookmarks (tap to jump back), Libby/Audible switcher | |

**Tapping any recent item plays it** without opening its app (book: resumes or plays it in Libby or
Audible; song/album/mix: YouTube Music finds and plays it). This uses the same requests Android Auto
and Assistant send; the app only opens if it turns the request down.

Both: up next, progress bar with times, live "time left", update symbol, and on every smaller size
**tap the art or text to open the full panel**: the biggest layout, floating over your home screen.

Sizes: **1×1** art · **2×1** art + text · **3×1** thirds: art | text | 2×2 recent grid ·
**4×1** + quick action, next, recent covers · **2×2** big art + text · **3×2/4×2** everything but
lists · **2×3+** + recent list · **4×3+** everything.

## Updating
Install **Widget Updater** (https://github.com/jonomf/widget-updater/releases/latest). It checks
GitHub for all widget apps, and when a newer build of this one is out the widget shows a small
**↑ symbol** (beside the title; top corner at 1×1). Tap it to install the update.

This app itself stays offline: an in-app updater (build 6) combined notification access with
internet + app-install permissions, which Play Protect blocks outright as a fraud/dropper pattern.
Without the Updater: long-press → settings entry → **Get the latest build in the browser**.

## Setup
1. Open **Audiobook** → **Allow notification access** → turn it on.
   - If the switch is greyed out ("Restricted setting"): in the app, tap **Open app info** →
     ⋮ (top right) → **Allow restricted settings**, then try again.
2. Tap **Add widget to home screen**, or long-press the home screen → Widgets → Audiobook.

Notification access is the Android permission that lets an app see and control
other apps' media sessions. This app only looks at Libby and Audible.

## How it works
- `MediaListener` is a notification-listener service. It watches Libby's and Audible's
  media sessions and redraws the widget when playback or metadata changes.
- `Profile` (Sources.kt): BOOKS and MUSIC, and which apps each follows.
- `Player` / `PlayActivity`: play a recent item in its app without opening it (live session, or via
  the app's media browser service); opens the app only as a fallback.
- `WidgetRenderer` draws both widgets with one code path: one layout per size (see `Kind`), and a
  per-profile model (`booksModel` / `musicModel`) supplies content and which controls apply.
- Layouts are generated by `tools/gen_layouts.py` (edit there, then run it), so every size and both
  widgets stay consistent.
- `MediaWidget` is the shared provider; `AudiobookWidget` and `MusicWidget` just pick a profile.
- `PanelActivity` is the expand panel; it draws the XL layout with the same code.
- `ArtProvider` serves the saved covers to the launcher by URI.
- `Store` keeps recent books across Libby and Audible; `MusicStore` keeps recent songs and the
  albums/mixes they came from (separate prefs and cover files).
- `RecentFetcher` asks apps that aren't running for their last-played book (media browser "recent" root), best effort.
- To follow another app, add it to `Sources.kt` and to `<queries>` in the manifest.


Every push to `main` builds a new APK release tagged `build-N` (GitHub Actions); N is the versionCode.
